# EduManager Pro - Student Management System

A modern Android application for managing student records, built with Jetpack Compose and Material 3.

## 🚀 Features
- **Splash Screen**: Professional entry animation.
- **Secure Login**: Authentication layer (open access for demo).
- **Dashboard**: Quick stats and action shortcuts.
- **Student Directory**: Searchable list of all registered students.
- **Registration**: Form to add new students with local persistence.
- **Profile View**: Detailed student information.

## 🛠️ Tech Stack
- **Language**: Kotlin
- **UI Framework**: Jetpack Compose
- **Navigation**: Compose Navigation
- **Architecture**: MVVM
- **Persistence**: Local File-based Storage
- **Design**: Material 3

## 📂 Project Structure
- `app/src/main/java/com/example/myapplication/`
    - `MainActivity.kt`: Main entry point and Navigation Host.
    - `StudentScreens.kt`: All UI Composable screens.
    - `StudentViewModel.kt`: Logic and data persistence.
    - `Student.kt`: Data model.

## 📝 Logbook / Report
- **Phase 1**: Requirement gathering and basic architecture setup.
- **Phase 2**: Implementation of core navigation and student data models.
- **Phase 3**: UI overhaul using Material 3 and custom design elements.
- **Phase 4**: Added persistence and search functionality.

## 🎨 Design Reference
The UI was inspired by modern educational platforms, focusing on clean typography and high-contrast interactive elements.
